# CELIA

**Local AI for evidence-based tender preparation.**

CELIA is an AI platform being developed for LEO MINOR to help analyse tender documents and prepare structured responses. It is designed to run locally and keep confidential business documents within the company's environment.

## Project goals

- Analyse tender requirements and retrieve relevant supporting documents.
- Reuse authorised historical tender files to reflect the company's established working methods.
- Assist with document drafting and identify missing evidence or inconsistencies.
- Keep generated statements traceable to their sources, with human validation before use.

## Approach

The project combines local language models, document processing, and hybrid search. Historical material must be checked against current tender requirements and verified evidence before reuse.

The intended benefits are less repetitive document searching, better preservation of institutional knowledge, and more consistent tender preparation.

## Status

CELIA is under development. This repository provides a public project overview; application code and confidential business documents are maintained separately.
